## Summary
Github Actions を作るうえで必要なのは最低限以下3つの設定

name:
ワークフローの名前

on:
ワークフローのトリガー。
プルリクエスト作成時とか、issueクローズ時とか、いろいろな種類のイベントをトリガーにできる。
トリガーとなったイベントの方法は github.event.<event-name> で取り出せる (例: github.event.pull_request.number)

jobs:
ワークフロー内で実行されるジョブ群。
最低ひとつから設定が必要。
やりたいことによってここが一番差が出る

## jobs で最低限必要な工程
runs-on:
ディスクイメージを指定する。ubuntu-latest とかを入れる。
実行環境の基盤になるので、これがないとはじまらない。
実行が単純なものなら slim ってついてるディスクイメージを指定することで、ディスクイメージを読み込む時間を減らせる。

permissions:
ジョブに実行権限を与える。issues: write みたいに対象のデータ+権限種別を指定する。
必須ではないが、だいたい必要になることが多い印象

env:
ジョブ実行中に参照させたい環境変数を指定する。
GITHUB_TOKENはPRの作成とかでよく使うので、 GH_TOKEN: ${{ secrets.GITHUB_TOKEN }} みたいな感じで作っておく機会が多いかも

uses: actions/checkout@vN
現在のリポジトリを参照させるためにチェックアウトさせる必要がある。そのために必要な操作
